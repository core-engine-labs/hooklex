# What is hooklex?

**hooklex** is a webhook and HTTP request inspection tool built for developers who need to see exactly what's hitting their endpoints — in real time, with zero setup friction.

Whether you're debugging a third-party integration, testing a payment gateway, or tracing a misbehaving webhook, hooklex gives you a dedicated URL, a beautiful request viewer, and all the context you need to move fast.

<Callout type="info">
  hooklex is designed for **developers first**. Everything from the UI to the export options is built around real debugging workflows.
</Callout>

## How it works

1. **Create a collection** — Group related webhook endpoints into a named collection, just like a Postman workspace.
2. **Get your endpoint URL** — Every collection gives you a unique URL ready to receive any HTTP request.
3. **Inspect incoming requests** — See headers, query params, body, IP address, method, and timing — all rendered beautifully.
4. **Replay, export, or forward** — Reproduce any request on demand, export data in multiple formats locally, or forward requests to your own server using Custom Actions (Paid — Cloud Version Coming Soon).

## Who is hooklex for?

hooklex is the right tool if you:

- Build integrations with third-party services (Stripe, GitHub, Shopify, etc.)
- Need to debug webhooks locally or in staging without exposing your server
- Want a clean, structured history of all incoming HTTP traffic
- Need to replay requests to reproduce bugs without re-triggering the original event
